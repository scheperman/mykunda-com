E-mail notificaties deployen

Volg deze 4 stappen om automatische e-mails werkend te krijgen. Na afloop ontvangen gebruikers een bevestiging en krijg jij een notificatie bij elke lead.

Database aanmaken

De tabellen in Supabase waar leads worden opgeslagen.

Dit heb je al gedaan. Het schema.sql is uitgevoerd en leads worden opgeslagen in de leads tabel.
✓ Klaar
2

Supabase koppelen

De API-keys zijn al ingevuld in supabase.js.

Dit heb je al gedaan. Project URL en anon key staan in supabase.js.
3

Resend instellen (e-maildienst)

Resend is de dienst die de e-mails daadwerkelijk verstuurt. Gratis tot 3.000 e-mails/maand.

  1. Ga naar resend.com/signup en maak een gratis account aan
  2. Ga naar Domains in het menu en klik Add Domain
    mykunda.com
  3. Resend geeft je DNS-records (SPF + DKIM). Log in bij je domeinregistrar (waar je mykunda.com hebt gekocht) en voeg deze records toe.

    Tip: Dit zijn meestal 2–3 TXT-records. Het kan 5–30 minuten duren voordat ze actief zijn. Resend laat een groen vinkje zien als het klaar is.
  4. Ga naar API Keys in het Resend-menu en klik Create API Key. Geef hem de naam mykunda-production en kopieer de key (begint met re_...).
    Bewaar deze key! Je ziet hem maar één keer. Je hebt hem nodig in stap 4.
4

Edge Functions deployen

Dit plaatst de e-mailcode op de Supabase-server zodat elke lead automatisch e-mails triggert.

  1. Installeer de Supabase CLI
    Open een terminal (Mac: Terminal app, Windows: PowerShell) en voer uit:
    npm install -g supabase
    Geen npm? Installeer eerst Node.js (LTS-versie). Dat installeert npm automatisch mee.
  2. Log in bij Supabase
    supabase login
    Er opent een browserpagina — klik op Authorize.
  3. Koppel je project
    supabase link --project-ref jejaerpqltqryqzjvbjp
    Als er om een database-wachtwoord wordt gevraagd, vul het wachtwoord in dat je hebt gekozen bij het aanmaken van je Supabase-project.
  4. Stel de geheime sleutels in
    Vervang re_JOUW_KEY_HIER door de Resend API key uit stap 3:
    # Voer deze 3 commando's één voor één uit: supabase secrets set RESEND_API_KEY=re_JOUW_KEY_HIER supabase secrets set LEAD_EMAIL=info@mykunda.com supabase secrets set FROM_EMAIL="MyKunda <noreply@mykunda.com>"
  5. Navigeer naar de backend-map
    Ga in de terminal naar de map waar je project staat:
    cd /pad/naar/jouw/project/backend
    Tip: Op Mac kun je cd typen (met spatie) en dan de map vanuit Finder naar de terminal slepen.
  6. Deploy de functies
    # Lead-notificaties (contact, valuation, etc.) supabase functions deploy notify-lead --no-verify-jwt # Viewing-notificaties supabase functions deploy notify-viewing --no-verify-jwt
    Als je Function deployed successfully ziet, is het gelukt!
✓

Testen

Controleer of alles werkt.

  1. Ga naar de Contact-pagina en vul het formulier in met je eigen e-mailadres
  2. Je zou nu twee e-mails moeten ontvangen:
    • info@mykunda.com — team-notificatie met alle ingevulde gegevens
    • Jouw e-mailadres — bevestigingsmail ("Thank you, [naam]!")
  3. Check ook de Home-pagina → valuatie-formulier. Daar zou je een bevestiging met prijsschatting moeten ontvangen.
Geen e-mail? Check je spam-map. Als Resend nog niet je domein heeft geverifieerd, kunnen e-mails geweigerd worden. Wacht tot het groene vinkje verschijnt bij Domains in Resend.
