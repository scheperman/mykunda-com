WhatsApp Business API — stap voor stap

Alles wat je moet doen om WhatsApp-notificaties en inbound lead capture live te zetten voor MyKunda. Van Meta-account tot deployment.

Geschatte tijd~2 uur + wachttijd
VereistMeta Business account
KostenGratis (eerste 1000/maand)
★

Wat wordt er live?

Na deze setup

✅ Agents krijgen een WhatsApp-bericht bij elke nieuwe lead of viewing request
✅ Gebruikers kiezen zelf of ze notificaties via email, WhatsApp, of beide willen
✅ Kopers die het MyKunda WhatsApp-nummer berichten, worden automatisch als lead aangemaakt in Supabase

1

Meta Business account aanmaken

Dit is de basis — je hebt dit nodig voor de WhatsApp Business API.

Ga naar business.facebook.com

Log in met een Facebook-account (of maak er een aan). Klik op "Create Account" en vul de bedrijfsgegevens in: MyKunda, mykunda.com, The Gambia.

Verifieer je bedrijf

Meta vraagt om verificatie (passport/ID + bedrijfsdocument). Dit duurt 1–3 werkdagen. Begin hier dus als eerste.

Voeg WhatsApp toe als product

In het Meta Business dashboard → All Tools → WhatsApp (of zoek op "WhatsApp Manager"). Klik "Get Started" om een WhatsApp Business Account aan te maken.

2

Telefoonnummer koppelen

Het nummer waarop kopers MyKunda kunnen bereiken.

Kies een nummer

Gebruik het bestaande MyKunda-nummer: +220 272 0268. Of koop een nieuw nummer. Het nummer mag niet al gekoppeld zijn aan een persoonlijke WhatsApp.

Registreer in WhatsApp Manager

WhatsApp Manager → Phone Numbers → Add Phone Number. Kies verificatie via SMS of voice call.

Stel het profiel in

Upload het MyKunda-logo, vul in:
• Display name: MyKunda
• Category: Real Estate
• Description: Property platform for The Gambia
• Website: https://mykunda.com

Let op: als je +220 272 0268 nu al als persoonlijke WhatsApp gebruikt, moet je dat eerst verwijderen (WhatsApp → Settings → Account → Delete Account). Je kunt het nummer daarna koppelen aan de Business API.
3

API-toegang instellen

De credentials die de Edge Functions nodig hebben.

Maak een System User aan

Meta Business → Settings → Business Settings → Users → System Users → Add. Geef het de naam "MyKunda API" en rol Admin.

Genereer een permanente token

Klik op de System User → Generate New Token. Selecteer je WhatsApp app en voeg deze permission toe:
• whatsapp_business_messaging
• whatsapp_business_management

Klik Generate. Kopieer de token — je ziet hem maar één keer.

Noteer het Phone Number ID

WhatsApp Manager → Phone Numbers → klik op je nummer → het Phone Number ID staat bovenaan (een getal als 123456789012345).

WatWaar te vindenVoorbeeld
WA_ACCESS_TOKENSystem User → Generate TokenEAABs…(lang)
WA_PHONE_NUMBER_IDWhatsApp Manager → Phone Numbers123456789012345
WA_VERIFY_TOKENKies zelf (bv. mykunda_wa_2026)mykunda_wa_2026
4

Message Templates aanmaken

WhatsApp vereist goedgekeurde templates voor het eerste bericht aan een gebruiker.

WhatsApp Manager → Message Templates → Create Template

Template naamCategoryBody tekst
lead_notificationUTILITY New enquiry from {{1}} about {{2}} on MyKunda. Log in to your dashboard to respond.
viewing_requestUTILITY {{1}} has requested a viewing for {{2}}. Open your dashboard to accept or propose times.
listing_alertUTILITY New property in {{1}}: {{2}} — {{3}}. View it on MyKunda: {{4}}
Goedkeuringstijd: templates worden door Meta gereviewd. Dit duurt meestal enkele minuten tot 24 uur. De status is zichtbaar in WhatsApp Manager.
5

Secrets instellen in Supabase

De Edge Functions lezen deze secrets automatisch.

supabase secrets set WA_PHONE_NUMBER_ID=123456789012345
supabase secrets set WA_ACCESS_TOKEN=EAABs...jouw_token_hier
supabase secrets set WA_VERIFY_TOKEN=mykunda_wa_2026

Controleer met:

supabase secrets list
6

Edge Functions deployen

Twee nieuwe functies naast de bestaande notify-lead en notify-viewing.

cd backend

supabase functions deploy wa-notify    --no-verify-jwt
supabase functions deploy wa-inbound   --no-verify-jwt

Test of wa-notify werkt:

curl -X POST https://YOUR-PROJECT.supabase.co/functions/v1/wa-notify \
  -H "Authorization: Bearer YOUR_ANON_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to": "+220XXXXXXX", "template": "lead_notification", "params": ["Test User", "Test Property"]}'
7

Inbound webhook configureren

Zodat inkomende WhatsApp-berichten automatisch leads worden.

Open WhatsApp Manager → Configuration

Scroll naar Webhook en klik Edit.

Vul de Callback URL in 
https://YOUR-PROJECT.supabase.co/functions/v1/wa-inbound

Vervang YOUR-PROJECT door je Supabase project ref (bijv. jejaerpqltqryqzjvbjp).

Verify Token

Vul exact dezelfde waarde in als je WA_VERIFY_TOKEN secret: mykunda_wa_2026

Subscribe to: messages

Vink messages aan. De andere velden (message_deliveries, message_reads) zijn optioneel.

Klik Verify and Save

Meta stuurt een GET request naar je webhook — de wa-inbound Edge Function beantwoordt dit automatisch.

8

Database-migratie uitvoeren

De notification_prefs tabel moet aangemaakt worden.

Open Supabase → SQL Editor → New Query. Plak en run het onderste deel van schema.sql (alles onder het kopje "SPRINT 5 — WHATSAPP & NOTIFICATION PREFERENCES").

Dit maakt de notification_prefs tabel aan met RLS policies en een auto-create trigger.

9

Testen

Stap voor stap checken of alles werkt.

  • Outbound test: Ga naar Dashboard → Notifications → selecteer "WhatsApp" → vul je nummer in. Dien een testformulier in (valuation of contact) en check of je een WhatsApp ontvangt.
  • Inbound test: Stuur een WhatsApp naar het MyKunda-nummer (bijv. "Hallo, ik zoek een huis in Kololi"). Check in Supabase → leads tabel of er een nieuwe rij is met source = 'whatsapp_inbound'.
  • Template test: Controleer in WhatsApp Manager → Message Templates dat alle drie templates status APPROVED hebben.
  • Dashboard: Log in, ga naar Dashboard, en schakel tussen Email / WhatsApp / Both. Check of de keuze wordt opgeslagen in notification_prefs.

Go-live checklist

  • Meta Business account aangemaakt en geverifieerd
  • WhatsApp Business Account aangemaakt in WhatsApp Manager
  • Telefoonnummer gekoppeld en profiel ingesteld
  • System User met permanent token aangemaakt
  • 3 message templates aangemaakt en goedgekeurd
  • Supabase secrets ingesteld (WA_PHONE_NUMBER_ID, WA_ACCESS_TOKEN, WA_VERIFY_TOKEN)
  • Edge Functions wa-notify + wa-inbound gedeployed
  • Webhook geconfigureerd in Meta met correcte URL + verify token
  • Schema migratie uitgevoerd (notification_prefs tabel)
  • Outbound test geslaagd — je ontvangt een WhatsApp bij een nieuwe lead
  • Inbound test geslaagd — een bericht naar het nummer maakt een lead aan
